# 登录渲染与只读路由拆分

用户已确认：登录渲染和管理员只读路由可抽离；保持接口、鉴权、GET/HEAD、请求倍率快照和页面行为不变。不推送、不部署。

## 模块边界

- `auth_views.py`：管理员登录及旧用户登录渲染函数，通过显式回调接收页面包装、图标、提示渲染和密码长度，不导入主服务、不读业务状态。旧用户登录仅保留原函数兼容，不恢复公开入口。
- `admin_read_routes.py`：仅处理 `/admin/usage`、`/admin/analytics.json`、`/admin/usage-history`、`/admin/usage.json`、`/admin/usage.csv`、`/admin/health`、`/admin/health.fragment`。使用冻结上下文和显式回调，每个请求动态组装，避免绑定旧测试替身或旧配置。
- 主服务继续负责 Token 换会话、所有写操作、未知路由404、公共安全头和失败关闭；新分发器在原 Token 交换之后调用。未命中时返回 False，不触碰鉴权或状态。

## 契约

保留 HTML 未登录跳转、JSON/片段401、CSV无效参数400、查询参数默认值、summary模式、导出文件名、健康片段双格式、缓存与HEAD行为。不缓存上下文中的请求倍率，不提前调用数据回调。

## 验收

登录HTML以拆分前正文哈希为回归基线，包括错误转义与用户身份提示；既有真实登录测试继续覆盖认证。七个路由用本机隔离HTTP服务验证登录/未登录、GET/HEAD、参数和导出；外部探测使用定向替身。新增模块纳入严格静态检查、部署复制/权限、持久回滚登记及恢复白名单。全套测试必须通过，不执行线上操作。
