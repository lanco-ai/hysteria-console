# 首页设计与实现

延续管理员登录页的暖白、深墨、冰蓝配色，使用原创 SVG 拓扑和点阵背景。
灵感来自 React Bits Dot Grid 的精细背景与 Aceternity Spotlight 的柔和光晕。

结构：品牌导航、左右首屏、三张服务能力卡片、宽幅控制台预览、收尾入口与页脚。
协议仅列 Hysteria2、VLESS Reality、TUIC，避免把客户端当作协议。

预览提供流量分析、用户管理、健康状态三个页签，所有数据明确标注为示例。
公开页面不请求用户、凭据或内部健康状态。无 JavaScript 时三个区域顺序展示。
页签支持点击、左右方向键、Home/End、空格；减少动态效果设置不影响切换功能。

桌面双栏，手机单栏。验证 320/390/768px 宽度、键盘切换、无 JS 回退与减少动效。
