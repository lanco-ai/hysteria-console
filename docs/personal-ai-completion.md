# 个人学习 AI 功能补齐

## 已确认范围（2026-09-29）

用户要求完整实现：持久聊天；论文、文档、图片与扫描件解析；个人语义知识库；公式和内容展示；问题编辑、重新生成、分支；学习项目与长期上下文；搜索、MCP、Python 执行；与学习日记联动。

用户明确排除：团队、权限运营、积分、支付，以及费用计算、预算提醒和限额。保留已有请求次数和服务返回的 Token 统计。

本次直接由当前模型实现，不启用模型编排工作流。沿用已授权的提交与部署，在集成前检查主分支并保留其他页面的并行更新。

## 运行方式与边界

- Word 支持 `.docx`；图片支持 PNG/JPEG/WebP。文档 ≤10 MB、PDF ≤200 页且扫描页 ≤30；图片 ≤4 MB/800 万像素。图片发送给视觉模型前会生成去除 EXIF 的 JPEG，模型本身需要支持视觉输入。扫描 PDF 在后台使用 Tesseract 中英文 OCR，结果可从引用原文核对。
- 文档原件、页段、图片预览、语义向量、对话、分支、工具结果与生成文件保存在私有 SQLite 中。升级保留 v1 数据；现有 SQLite 在线备份包含新增表。MCP 凭据也在该私有数据库，但不进入普通工作区 JSON 导出、模型提示词或公开配置接口。
- 语义索引使用本地 `Xenova/multilingual-e5-small` 量化 ONNX，固定提交 `761b726dd34fb83930e26aab4e9ac3899aa1fa78`，原始 E5 模型为 MIT 许可；代码未复制 Aivory。模型下载脚本校验 SHA-256，不执行 Hugging Face 仓库代码。使用与官方 tokenizer 核对过的 SentencePiece / XLM-R ID 映射以减少内存。
- 自动摘要在近期上下文装不下时调用当前聊天模型，保留原历史；摘要失败会明确提示并保留已有摘要和近期消息。项目记忆需本人确认保存，可编辑删除。私人日记不会自动加入对话。
- 搜索无需额外 API key，使用 DDGS 公共搜索结果；公开网页只读取 HTTPS，检查 DNS 所有地址并固定连接 IP，每次重定向重新校验。搜索引擎限流或网页拒绝读取时会报告失败。
- MCP 支持 Streamable HTTP、初始化/会话/JSON/SSE、分页工具发现、参数校验及调用。暂不包含本机 stdio 进程启动或 OAuth 浏览器授权；需连接此传输的 MCP 端点，可填写 Bearer 凭据。默认禁止内网地址，单个连接可由用户明确允许。工具定义和结果是第三方数据，执行前显示参数并要求确认，重复执行请求不会重放外部操作。
- Python 使用独立 Docker 镜像（标准库、NumPy、Matplotlib），普通 UID 65534、禁网、根文件系统只读、移除全部 capabilities、禁止提权、默认 seccomp/AppArmor、无主机挂载或 Docker socket。单次 ≤40 秒/192 MB/0.5 CPU/32 进程；输入资料需明确选择；输出最多 8 个文件、单个 ≤2 MB、合计 ≤6 MB。
- 文档原件总额 ≤200 MB；工具文件总额 ≤50 MB。新增文件前保留至少 128 MB 磁盘余量。服务器磁盘较小，实际可用上传空间受剩余磁盘限制。

## 依赖与恢复

全新环境使用 `bash scripts/prepare-learning-runtime.sh` 安装 OCR、Web 依赖、独立向量推理环境、固定模型以及沙盒镜像；脚本不会重启服务。常规代码发布继续通过项目部署文件清单管理新增模块。本次线上发布应只切换 React 资源及 Web API，并重启 `hysteria-react.service`；代理服务配置保持现状。

可选部署变量：`HY2_EMBEDDING_PYTHON`、`HY2_EMBEDDING_MODEL_DIR`、`HY2_PYTHON_IMAGE`。非默认 `HY2_HY_DIR` 的主机应同步设置前两项。模型和沙盒镜像是可重建依赖，不应放进每日用户数据备份。

在 v2 数据库上回滚代码时，应保留理解 v2 表结构的存储代码；不可用旧 v1 程序覆盖新数据库。先备份数据再切换，优先前滚修复。删除工具记录或对话不会撤销已执行的外部 MCP 操作。
