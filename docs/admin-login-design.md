# 管理员登录页

沿用后台浅色风格：暖白底、深墨色文字与按钮、冰蓝色网络节点。
桌面左右双栏，左侧品牌与装饰网络图，右侧管理员表单；800px 以下隐藏装饰区。

页面移除用户身份切换，仅展示管理员账号和密码。保留现有管理员 POST 字段、鉴权、限流和会话机制。此变更不删除代理用户或订阅记录。

密码显示按钮只在 JavaScript 可用时出现；提交显示验证进度，浏览器返回后重置状态；错误文本转义，密码不回填。关闭动画偏好下禁用入场效果。

视觉灵感：Aceternity Spotlight New 的柔和光晕、React Bits Dot Grid 的细密背景。使用原创本地 SVG 和 CSS 实现，不加载外部动画脚本。

验证：管理员成功和失败登录、表单标签与转义、密码切换、提交状态、历史返回、手机无横向溢出及减少动态效果偏好。
