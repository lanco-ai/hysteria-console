# 健康页与导航改进方案

保留现有服务端渲染界面，不引入 React 迁移。

- 健康页每 30 秒请求同一批状态响应，更新核心服务、重复的基础设施状态、顶部指标和更新记录。请求失败保留旧值并提示；隐藏页面停止轮询。
- 更新操作区保留原接口与确认步骤，正在操作或聚焦时不替换按钮。状态和策略跳过原因使用中文，时间由浏览器转换成本地时间。
- 线路雷达和费用校准保留输入状态，不随轮询替换表单。
- 手机用户表转为纵向卡片，保留语义表头、筛选隐藏状态，长名称与备注换行。
- 模板编辑框提供可访问名称和真实存在的帮助文本引用。
- 验证鉴权、状态响应、导航结构和原有功能回归；真实更新、删除用户等操作使用测试替身，不在生产环境执行。
